# 常见问题

| 情况 | 检查方法 |
| --- | --- |
| 电脑 `127.0.0.1:4317` 拒绝连接 | 先看后台是否启动、4317 是否被其他程序占用，再看本项目 `.runtime/service-*.stderr.log` |
| 手机显示“等待电脑完成设置” | 在电脑本机页面使用设置码创建首个管理员；远程不能初始化 |
| 手机访问 `127.0.0.1` 失败 | 手机的回环地址是手机本身；浏览器用电脑显示的局域网地址，App 用构建时的 HTTPS 地址 |
| DDNSTO 设备离线 | 检查独立 DDNSTO 客户端、电脑网络和睡眠状态；重启工作台不会自动修复 DDNSTO |
| DDNSTO 在线但页面打不开 | 目标应为 `http://127.0.0.1:4318`，后台须启用 ddnsto 模式，HTTPS 域名须匹配 |
| DDNSTO 提示浏览器登录了其他账号 | 这是隧道入口的账号校验；按页面提示切换到域名所属的 DDNSTO 账号，再登录工作台。DDNSTO 账号与工作台账号是两套账号 |
| App 提示连接验证 | 登录页更多 → 连接与账号；已登录时“我的 → 连接信息 → 连接验证”，由本人完成后返回 |
| 重启后要求登录 | 会话在内存中，后台重启后失效；用原账号登录，不用重新创建账号 |
| 忘记密码、想查看密码 | 管理员在网页“管理员 · 账号与密码”主动查看；旧账号只有校验值，先重新设置才能查看。当前管理员本人改密需要原密码，没有匿名找回入口 |
| 提示密码显示密钥不可用 | 恢复原 `.runtime/password-view.key` 后重启后台，不要随机替换密钥；已有账号仍可用原密码登录 |
| 提示已保存的密码无法读取 | 核对账号文件与密钥是否为同一套备份；密钥完整而单个记录损坏时由管理员重新设置该账号密码 |
| 任务显示结果未知 | 先刷新状态并阅读对话，确认是否已执行；不要自动重发 |
| 选择了 PPT，Codex 仍说没收到 | 必须看到“已上传 · 待发送”后再点发送；仅选择文件或上传完成不会自动提交需求 |
| 文件管理器无法读取文件 | 文件先下载到本机，尝试“换一种方式选择”；文件需为有效 .docx / .pptx 或受支持图片 |
| 选不到图片或只提示 Word / PPT | 更新 App 和电脑后台；新版支持 JPG / PNG / 静态 WebP，不支持 GIF、HEIC 或动态 WebP |
| PPT 超过大小限制 | 单文件上限 100 MiB，压缩图片或拆分；不支持超限压缩包或加密文件 |
| 上传返回后找不到附件 | 回到原任务，检查顶部上传提示；不要在另一任务找。强制关闭 App 后草稿不保证恢复 |
| 技能不可用 | 对应技能需安装在电脑 Codex 中，且启用状态、名称及插件标识匹配。可先选“不指定” |
| 官方桌面提示任务在另一个应用打开 | 等当前手机执行完成后重试；新版后台会释放自己空闲的会话。桌面代执行需使用兼容版本、同一 Windows 用户及登录会话 |
| 桌面任务显示“遇到了问题” | 更新后台的桌面输入兼容修复，再重试；必要时等待所有桌面任务完成后重启桌面应用。不要删除任务或历史文件 |
| 手机提示请在电脑确认 | 到桌面原任务处理权限确认或追问；手机不代替桌面批准 |
| 手机提示任务已归档 | 在电脑取消归档，再刷新状态并手动发送；也可新建任务。后台不会自动取消归档或自动重发 |
| 旧任务恢复到手机失败 | 协议不兼容时等电脑执行完成，按需退出官方桌面 Codex，再“恢复工作台操作”；手机不能强制释放桌面任务 |
| 关闭桌面后工作台也停止 | 使用新版 `npm run start:background` 启动独立后台；此前已启动的旧进程需要先停止。电脑睡眠、关机仍会影响服务 |
| 新 APK 无法覆盖安装 | 检查包名、versionCode 和签名是否一致；新生成的签名不等于原签名 |
| 构建提示缺少路径 | 按 ANDROID.md 设置 JAVA_HOME、ANDROID_BUILD_TOOLS、ANDROID_JAR 与服务地址，使用实际安装目录 |
| 共享后其他账号仍看不到 | 对方等级必须不低于项目等级；私有状态下其他人始终不可见 |

报告问题时说明 App 版本、Windows / Android 版本、操作步骤和去除私人信息后的错误文字。不要提交密码、Token、签名文件、完整 `.runtime` 或私人 Office 文档。
