# 使用说明

## 项目和任务

登录后，App 首页只显示项目卡片。点击项目进入任务列表，再点击任务进入对话。“我的”集中放置账号、等级、修改密码、连接信息、检查更新和退出登录。

每个新项目有独立目录，同一项目里的任务共用该目录。需要独立保存成果时请创建新项目。项目默认私有，普通用户可在创建时预设等级，创建后等级由管理员调整。

在任务中输入需求并发送。回复和执行状态会自动刷新；任务执行中可先写下一条草稿，但不能同时启动第二轮。需要中断时从更多菜单停止。若显示“结果待确认”，先刷新核对对话，不要重复提交同一需求。

## 上传图片、文档与下载成果

1. 点击输入框左侧回形针，从手机选择 JPG / PNG / 静态 WebP 图片，或 `.docx` / `.pptx` 文档。
2. 等待显示“已上传 · 待发送”，再填写需求或直接发送。
3. 手机选择文件不等于 Codex 已经收到本条需求。完成上传后还需要点击发送。
4. 每条需求最多三个附件，可混合图片和文档，单个最多 100 MiB。旧版 `.doc` / `.ppt`、加密文档、GIF、HEIC 和动态 WebP不支持。

可以返回上一层或切换任务，上传完成后保留在原任务中；点击上传状态可返回。上传依赖当前 App 进程运行，不承诺在强制关闭 App 或被系统清理后继续。草稿在当前运行期间保存，退出账号后清除。

如果手机文件管理器提示无法读取，尝试提示中的“换一种方式选择”；确认文件已实际下载到手机。可在项目文件中重新选择已经上传的附件。卡片上的 × 只是取消本条需求的引用，文件仍在电脑项目中。

右上角文件入口可刷新和下载成果。共享用户只可查看、下载；文件列表和下载接口都会检查项目权限。当前手机附件选择器尚不支持上传 Excel 或 PDF。

## 选择常用技能

输入区点击“技能”，每次可选择一项：

| 技能 | 示例需求 |
| --- | --- |
| Word 文档 | 把会议要点整理成一份 Word 纪要 |
| PPT 演示 | 根据需求制作一份课程演示文稿 |
| Excel 表格 | 新建一份带汇总公式的费用统计表 |
| PDF 处理 | 将项目中的材料整理为 PDF |
| 软件开发 | 在当前项目开发一个小工具并说明运行方法 |

也可以保持“不指定”。选择跟随当前任务草稿，切换任务不会带到别的任务，发送成功后清空；可与图片、Word / PPT 附件一起发送。

这些入口调用电脑已安装的技能。缺少、停用或不匹配时会提示不可用；源码仓库不包含这些插件。功能入口可用不等于任意文档任务的运行依赖都已就绪，应根据实际回复处理缺失工具。

## 私有、共享和等级

| 状态 | 谁能查看 | 谁能操作 |
| --- | --- | --- |
| 私有项目 | 所有者 | 所有者 |
| 共享项目 | 所有者及等级不低于项目等级的用户 | 所有者；其他人只读 |
| 网页已登记电脑任务 | 按项目可见性判断 | 当前为只读 |

项目接口不会因为管理员等级高就返回他人的私有内容，但管理员能够查看或重设账号密码，并用该账号登录。关闭共享后，其他用户失去后续访问；已下载的文件无法撤回。工作台账号不等于 Windows 独立账号，详见 [SECURITY.md](../SECURITY.md)。

## 删除、密码与更新

- 长按自己的项目卡片，或从项目更多菜单选择“删除项目”。确认后移除工作台项目与任务记录，保留电脑文件和原始 Codex 对话。当前没有项目恢复入口；运行中或待核实的任务须先处理。
- “我的 → 修改密码”需要当前密码，新密码至少六位。修改后所有设备重新登录，同时同步管理员可查看的密码。
- “我的 → 检查更新”检查自己的工作台发布的新版本。确认后下载、校验，再按安卓提示安装；首次可能需要由本人授予安装应用权限。App 不会静默代替用户完成系统安装。

## 管理员账号与密码

电脑网页展开“管理员 · 账号与密码”。创建普通账号时填写账号、初始密码和等级；输入框旁可以切换显示或隐藏密码。

- 已保存的密码默认以圆点显示，点击“查看密码”才展开，30 秒后自动隐藏。
- 老账号显示“需重新设置后才能查看”。点击“重新设置密码”，输入至少六位新密码并保存，再点“查看密码”。
- 保存后原密码失效，该账号所有设备重新登录；账号停用状态、等级、项目和文件保留。
- 当前管理员修改自己的密码时，点“修改我的密码”，需要填写原密码。
- 管理员查看功能只在网页提供，普通账号不能访问查看/重设接口；Android App 无需因为此功能重新安装。

## 手机与电脑共用会话

电脑打开网页工作台，在“手机任务”中用相同账号访问 App 的项目。App 不再提供电脑任务列表和新的“交给电脑”操作。

Windows 上，同一手机任务也可以在兼容的 Codex 桌面中打开。后台自己的执行完成后会释放空闲会话；若桌面已经占用，手机通过原桌面会话发送并查看进度。两端可以查看同一对话，每个任务仍只允许一轮执行，执行中须等待完成后再发送。

桌面代执行时沿用桌面任务的模型与权限设置。需要权限确认或回答时，手机会提示到电脑处理。连接中断或发送结果未知时先刷新核对；App 不自动重发，也不会强制关闭桌面任务。

旧版已移交的任务仍可在更多菜单选择“恢复工作台操作”。若桌面版本或连接不兼容，先等电脑执行完成，再按需退出官方桌面 Codex 后手动恢复。已归档任务需先在电脑取消归档，然后刷新并手动发送；也可新建任务。
